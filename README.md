## Огляд функціоналу
- **Повна адаптивність (Mobile First):** сайт автоматично оптимізується під смартфони, планшети, лептопи та широкоформатні монітори.
- **Темна кінематографічна тема (Dark Mode):** глобальна підтримка темного режиму через нативний атрибут `data-bs-theme="dark"`.
- **Адаптивна панель навігації (Navbar):**
  - Закріплена вгорі екрана (`fixed-top`) із ефектом матового скла (`backdrop-filter: blur(10px)`).
  - «Гамбургер»-меню на смартфонах.
  - Інтегрований **ScrollSpy** для динамічного підсвічування активних розділів під час прокручування.
- **Слайдер фільмів (Carousel):** карусель із постерами, описами та керуванням перемиканням.
- **Каталог кінострічок (Grid & Cards):**
  - 12-колонкова адаптивна сітка (`col-12 col-md-6 col-lg-3`).
  - Картки з постерами, бейджами рейтингу (`badge`) та кнопками.
  - Плавні мікроанімації при наведенні (Hover Effect з підйомом карток).
- **Форма зворотного зв'язку:** секція «Запропонувати фільм» із полями вводу та валідацією.
